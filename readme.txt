台灣鑽孔岩心照片自動化爬取工具 (Taiwan Drill Core Photo Scraper)

這是一個強大的自動化爬蟲工具，專門設計用來從政府開放平台（工程地質探勘資料庫地圖）批次下載全台灣的鑽孔岩心照片。它具備了突破 WAF 防火牆、座標轉換、自動處理 Base64 編碼圖片，以及斷點續傳等強大功能。

========================================
免責聲明與使用規範
========================================
本工具僅供學術研究與資料分析測試使用。請遵守目標網站的規範，切勿對伺服器發動阻斷服務攻擊 (DDoS) 或過度頻繁的請求。建議在離峰時間執行，並保持適當的請求間隔 (Sleep time)。


========================================
核心功能
========================================
* 突破防火牆封鎖：使用 Playwright 模擬真實無頭瀏覽器 (Headless Browser) 行為，自動處理 Cookie 與 TLS 指紋，繞過嚴格的 API 驗證機制。
* 精準座標轉換與打擊：內建 WGS84 轉 Web Mercator (EPSG:3857) 座標轉換函數，透過在每一口井周圍構造 100x100 公尺的小矩形 (Polygon) 進行精準的空間查詢，避免伺服器因資料量過大而回傳 500 錯誤。
* Base64 自動還原：自動從 JSON 回應中萃取 Base64 加密字串，並解碼還原成實體的 .jpg 岩心照片。
* 智慧命名系統：下載的照片會自動依據「案件編號_孔號_起始深度m-結束深度m.jpg」的格式命名，確保不同深度的照片不會互相覆蓋。
* 斷點續傳 (Log 機制)：自動建立 processed_log.txt。如果下載中斷或遇到網路問題，重新啟動程式會瞬間跳過已完成的紀錄，從中斷處繼續執行，不怕做白工。
* 資料 Metadata 匯出：內建附屬腳本，可自動比對照片檔名與原始 CSV 資料，產出具備明確經緯度座標的 core_photos_metadata.csv，方便無縫匯入 QGIS 或 ArcGIS 等空間資訊系統。


========================================
環境需求與安裝步驟
========================================

1. 系統需求
   * Python 3.8 或以上版本
   * 穩定的網路連線

2. 安裝必備套件
   請打開終端機 (Terminal 或 PowerShell) ，進入工具所在的資料夾，並執行以下指令，透過 requirements.txt 一次安裝所有需要的核心套件：
   
   pip install -r requirements.txt

   (如果你不想使用 requirements.txt，也可以手動輸入指令： pip install pandas playwright requests urllib3)

3. 安裝 Playwright 瀏覽器引擎
   這是本工具能成功繞過防護的關鍵，請務必執行此指令下載模擬用的 Chromium 瀏覽器：
   
   python -m playwright install chromium


========================================
執行教學
========================================

步驟一：準備輸入資料
請確保你的工作目錄中包含一個名為 all_taiwan_geotech_holes.csv 的檔案。
這個檔案必須包含以下欄位（大小寫須完全一致）：
* proj_no: 案件編號
* hole_no: 孔號
* coord_x: 經度 (WGS84)
* coord_y: 緯度 (WGS84)

步驟二：執行爬蟲主程式
將主程式儲存為 scraper.py，並在終端機中執行：
python scraper.py

執行時的畫面與流程：
1. 程式會先啟動無頭瀏覽器，造訪地圖首頁以獲取合法的 Cookie 與 Session 通行證。
2. 接著開始逐筆讀取 CSV。
3. 如果發現該筆紀錄在 processed_log.txt 內，會顯示「略過」並瞬間跳至下一筆。
4. 將經緯度轉換為 Web Mercator，並發送該點位的精準查詢請求，取得內部 keyid。
5. 拿 keyid 請求 Base64 照片字串，解碼並存入自動建立的 core_photos 資料夾中。
6. 單筆完成後寫入 Log，並等待 0.5~1.5 秒再進行下一筆。

步驟三：產出 GIS 詮釋資料 (可選)
當你下載完部分或全部的照片後，如果你需要將照片匯入 QGIS 進行展示，請將資料合併腳本儲存為 generate_metadata.py 並執行：
python generate_metadata.py

這支程式會掃描 core_photos 裡的每一張圖片檔名，與原本的 CSV 進行 Left Join 比對，最後產出一份名為 core_photos_metadata.csv 的新檔案。這份新檔案會清楚列出每一張照片對應的經度、緯度、起始深度與結束深度。


========================================
常見問題 (Q&A)
========================================

Q1: 為什麼程式卡在「正在造訪首頁以獲取通行證...」很久？
這通常是因為目標網站的首頁載入太慢或連線不穩。程式設有 30 秒的 Timeout，如果超過時間會拋出例外並結束。請確保你的網路連線正常，並稍後再重新執行。

Q2: 為什麼有些孔號顯示「該座標範圍內無此孔號」？
這可能是因為 CSV 中紀錄的經緯度座標，與目標網站資料庫中紀錄的位置有幾百公尺以上的偏差。程式預設搜尋半徑為 50 公尺（形成 100x100 的方塊），如果座標偏差過大，空間查詢就會找不到。你可以嘗試在程式碼中調整 offset 的數值（例如改為 200）來擴大搜尋範圍，但請注意不要設太大，以免又引發伺服器 500 錯誤。

Q3: 程式下載到一半斷線了怎麼辦？
不用擔心！直接重新執行 python scraper.py 即可。程式會自動讀取 processed_log.txt，並在幾秒鐘內跳過前面已經完成（或標記為無照片）的所有紀錄，精準從失敗的那一筆繼續下載。

Q4: 遇到 Timeout 60000ms exceeded 是什麼意思？
這代表伺服器已經接受了照片下載的請求，但是因為伺服器頻寬太小或照片檔案太大，在 60 秒內還沒傳輸完畢。程式會將此視為網路錯誤，該筆紀錄不會被寫入 log 檔，下次重跑時就會自動重試。
